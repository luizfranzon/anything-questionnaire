## Agent skills

### Issue tracker

Issues e specs ficam como arquivos markdown locais em `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Rótulos padrão (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), gravados como linha `Status:` em cada issue. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` e `docs/adr/` na raiz. See `docs/agents/domain.md`.
